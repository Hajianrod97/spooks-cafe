# Spook's Cafe

macOS Pomodoro tracker with a lofi theme (named Lofi Focus until step 6; the repo, crate, bundle identifier `dev.lofifocus.app` and data folder keep that name on purpose — changing the identifier would reset macOS permissions, the WebKit store and the login item). Full requirements and build order are in `SPEC.md` — read it before starting work, and keep it updated when decisions change. Known bugs and rough edges to fix later are in `DEFECTS.md`: add to it when you notice one, and tick items off when they're fixed.

## Working with the user
- The user is a mid-level engineer job-searching full-time and using this project to learn.
- Split: Claude builds the core; the user extends it later. "Later" items in SPEC.md are the user's practice tickets — don't build them unless asked. "Future" items in SPEC.md are features the user wants built together: design them in grilling rounds first.
- Teach while building: explain the *why* behind architecture and idioms (Tauri IPC, Rust, React patterns). Leave meaningful pieces (state machines, SQL queries, Tauri commands) for the user to write when the Learning output style is on.
- Code style: clean, idiomatic TypeScript/Rust; comments only where non-obvious.
- Give a recommendation when presenting options; don't just list them.

## Stack
- Tauri 2 + React + TypeScript (Vite), SQLite for storage.
- Run the app with `npm run tauri dev`.

## Environment
- Shell is fish. Rust/cargo are on PATH via `~/.config/fish/conf.d/rustup.fish`.
- Editor: VS Code.
